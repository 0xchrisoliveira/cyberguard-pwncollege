Este nível é engenhoso: a página de manual do desafio foi escondida com um nome aleatório.
Felizmente, todas as páginas man são reunidas em uma base de dados pesquisável, o que permite buscar no catálogo do sistema até encontrar a man page oculta do desafio!
Para aprender como pesquisar pela página de manual correta, consulte a própria manpage do comando `man` executando: `man man`!

---
**DICA 1:** `man man` ensina o uso avançado do próprio utilitário `man`, e você deverá usar esse conhecimento para descobrir como pesquisar pela manpage escondida que ensinará a usar `/challenge/challenge`.

**DICA 2:** Embora a página de manual tenha um nome aleatório, o executável que você chamará para obter a flag continua sendo `/challenge/challenge`!
