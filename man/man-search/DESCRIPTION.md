Você pode rolar as páginas do manual com as teclas de seta (e PgUp / PgDn) e realizar buscas digitando `/`.
Após iniciar a busca pelo termo desejado, pressione `n` para avançar até o próximo resultado e `N` (Shift + n) para retornar ao resultado anterior.
Em vez de `/`, você também pode utilizar `?` para pesquisar no sentido inverso (de baixo para cima)!

Encontre a opção que revelará a flag lendo atentamente a man page do comando `challenge`.
