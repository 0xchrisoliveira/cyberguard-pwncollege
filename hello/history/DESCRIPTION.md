Você vai digitar muitos comandos ao longo da jornada, e redigitar tudo do zero sempre pode ser cansativo.
Felizmente, a shell salva um _histórico_ (*history*) de cada comando que você executa.

Você pode navegar por esses comandos salvos usando as teclas de seta para cima e para baixo (↑ / ↓), e vamos praticar isso neste desafio.
Este desafio injetará a flag diretamente no seu histórico.
Abra um terminal, pressione a tecla de seta para cima (↑) e capture-a!
Em outros desafios, o histórico conterá o registro dos comandos que você já executou, então se precisar rodar um comando similar novamente, você pode usar as setas para rolar e encontrá-lo com facilidade!
