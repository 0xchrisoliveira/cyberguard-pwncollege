Neste desafio, você invocará seu primeiro comando!
Quando você digita um comando e pressiona Enter, o comando é executado, desta forma:

```console
hacker@dojo:~$ whoami
hacker
hacker@dojo:~$
```

Aqui, o usuário executou o comando `whoami`, que simplesmente imprime o nome do usuário atual (`hacker`) no terminal.
Quando o comando termina, a shell exibe o prompt novamente, pronta para o próximo comando.

Neste nível, invoque o comando `hello` para obter a flag!
Tenha em mente: comandos no Linux diferenciam maiúsculas de minúsculas (*case-sensitive*): `hello` é diferente de `HELLO`.
