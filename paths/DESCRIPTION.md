Este módulo ensinará os fundamentos sobre caminhos de arquivos (*paths*) no Linux!

O sistema de arquivos do Linux é estruturado como uma "árvore".
Isto é, ele possui uma raiz (*root*, representada por `/`).
A raiz do sistema de arquivos é um diretório, e cada diretório pode conter outros diretórios e arquivos.
Você faz referência a arquivos e diretórios por meio do seu _caminho_ (*path*).
Um caminho a partir da raiz do sistema de arquivos começa com `/` (ou seja, a própria raiz) e descreve o conjunto de diretórios pelos quais é necessário navegar para encontrar o arquivo.
Cada parte do caminho é separada por uma barra `/`.
