Você aprendeu a interromper processos com `Ctrl-C`, mas existem medidas menos drásticas para recuperar o controle do seu terminal!
Você pode *suspender* processos para o segundo plano com `Ctrl-Z`.
Neste nível, exploraremos como isso funciona e, no próximo nível, descobriremos como *retomar* esses processos suspensos!

O binário `run` deste nível quer ver outra cópia de si mesmo em execução *utilizando o mesmo terminal*.
Como fazer isso?
Use o terminal para iniciá-lo, suspenda-o com `Ctrl-Z` e, em seguida, inicie outra cópia enquanto a primeira permanece suspensa!
