No módulo sobre pipes (*piping*), você explorou o conceito de utilizar vários comandos, com dados fluindo entre eles através de canais, para realizar tarefas mais complexas do que comandos isolados conseguiriam fazer.
Naturalmente, esse conceito também se aplica de forma independente da transferência de dados: às vezes, você só deseja executar vários comandos em sequência rápida para obter um efeito cumulativo.

Este módulo abordará diversas maneiras, além dos pipes, pelas quais comandos podem ser encadeados.
Ao final, você estará a caminho de escrever seus próprios *shell scripts*!
