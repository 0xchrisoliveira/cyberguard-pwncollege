Mesmo após poucos níveis, você já deve estar cansado de ter que digitar todos esses caminhos de arquivos completos.
Felizmente, a shell tem uma solução prática: o *globbing*!
É exatamente isso que aprenderemos neste módulo.

Antes de executar os comandos que você digita, a shell realiza *expansões* (*expansions*) neles, e uma dessas expansões é o globbing (com caracteres coringa).
O globbing permite que você faça referência a arquivos sem precisar digitar o nome de cada um por extenso ou seus caminhos completos.
Vamos começar!
