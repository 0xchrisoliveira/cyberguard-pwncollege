Com o seu conhecimento sobre `cd`, `ls` e `cat`, estamos prontos para um pequeno jogo investigativo!

Começaremos na raiz `/`.
Normalmente:

```console
hacker@dojo:~$ cd /
hacker@dojo:/$ ls
bin   challenge  etc   home  lib32  libx32  mnt  proc  run   srv  tmp  var
boot  dev        flag  lib   lib64  media   opt  root  sbin  sys  usr
```

É bastante conteúdo!
Em breve você estará muito familiarizado com todos eles, mas você já deve reconhecer o arquivo `flag` e o diretório `challenge`.

Neste desafio, a *flag foi escondida*!
Aqui, você usará `ls` e `cat` para seguir as pistas e encontrá-la!
Veja como vai funcionar:

0. Sua primeira pista está em `/`. Dirija-se até lá.
1. Olhe ao redor com `ls`. Haverá um arquivo chamado HINT, CLUE ou algo nessa linha!
2. Use `cat` nesse arquivo para ler a pista!
3. Dependendo do que a pista disser, navegue até o próximo diretório indicado (ou não!).
4. Siga a trilha de pistas até a flag!

Boa sorte!
