A interface de linha de comando do Linux é, na verdade, uma sofisticada linguagem de programação com a qual você pode criar programas completos!
Como a interface de linha de comando é chamada coloquialmente de "shell", os programas escritos nessa linguagem são conhecidos como "scripts de shell" (*shell scripts*).
Quando você está interagindo no terminal, está essencialmente escrevendo e executando um script de shell linha por linha!

Como a grande maioria das linguagens de programação, a shell oferece suporte total a variáveis.
Este módulo tornará você fluente na definição, exibição, exportação e manipulação dessas variáveis!
