Vamos direto ao ponto!

O `screen` é um programa que cria terminais virtuais dentro do seu terminal.
É parecido com ter várias abas no navegador, só que para a sua linha de comando!

Iniciar o screen é extremamente simples:

```console
hacker@dojo:~$ screen
```

E só isso!
Agora você está dentro de uma sessão do screen.
Ela se parece _exatamente_ com um terminal convencional, mas existem novos recursos esperando para serem descobertos.

Para este desafio, configuramos tudo para que apenas iniciar o screen conceda a flag a você.
Fácil assim!

----
**NOTA:**
Quando terminar de usar a linha de comando, digite `exit` ou pressione `Ctrl-D` para sair da sessão do screen.
Em seguida, o screen será finalizado e retornará você à sua shell _original_.
